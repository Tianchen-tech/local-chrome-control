# 0.3.1 发布说明

2026-10-07。开发预览版，macOS 与 Windows 10/11，最低 Chrome 125。使用固定开发公钥，需解压加载；不是 Chrome 应用商店版本。

## 包含内容

0.3.1 将以下改动合并为同一版本：

- **Windows 支持**：0.3.0 Windows 预览（[v0.3.0-windows-preview.1](https://github.com/Tianchen-tech/local-chrome-control/releases/tag/v0.3.0-windows-preview.1)）及其后的修复——可重复执行的 NTFS ACL 设置、无控制台的可执行启动器，以及按原因区分的连接错误提示。安装与验收见 [WINDOWS.md](WINDOWS.md)，验证边界见 [WINDOWS-CI.md](WINDOWS-CI.md)。
- **重新设计的扩展弹窗**：
  - 以当前标签页状态为中心：未授权、授权中、已授权等待任务、正在控制、未连接、此页不支持，各有颜色与图标；正在控制时直接显示任务名。
  - 授权后显示剩余时间进度条与到期时刻。
  - 控制模式改为卡片选择，授权时长改为按钮；黑名单仅在扩展模式下出现。授权后设置自动收起，需要时点“调整权限”展开。
  - 授权与停止按钮固定在底部；内容适配 Chrome 弹窗 600px 高度上限。
  - 最近操作改为时间线：按操作类型显示图标、相对时间，常见失败原因以中文说明（原错误码在悬停提示中）；手动停止不再显示为失败。
  - 跟随系统深色模式；模式与时长使用原生单选控件，可键盘操作。
- **新图标**：浏览器窗口加点击中的指针。16/32px 为工具栏简化版；128px 按商店规范留 16px 透明边距。SVG 源文件位于 `assets/icon-source/`，弹窗页头使用 `extension/icons/icon.svg` 以保证高分屏清晰。

授权、控制范围、消息协议与安全检查均未改变；弹窗只调整界面与交互。

## 验证

- macOS 本机：`npm test` 138 项中 132 项通过，6 项 Windows 专用测试按平台跳过，0 失败；`npm run check` 通过。
- 弹窗各状态使用模拟数据在 Chrome 中检查了浅色与深色显示。新弹窗尚未在个人 Chrome 配置中完成实际授权流程复测。
- 合并到 main 后由 GitHub Actions 运行 Mac/Windows × Node 22.22.2/24 四组回归。

## 升级

从 0.3.0 或更早版本升级：替换源码目录后，在 `chrome://extensions` 确认扩展加载自新目录并点击“重新加载”，再在弹窗中重新授权标签页。旧扩展副本会被本机连接识别为 `EXTENSION_OUTDATED`。
