# 0.2.1：最高档默认允许普通网站，黑名单排除

选择“扩展 · 所有普通网站，排除黑名单”，点击“允许控制此标签页”，即可在这个标签页跨网站连续操作。黑名单可留空，无需输入允许访问的网址；跨源 iframe 使用同一规则。只读与标准两档保持当前 origin 的范围。

黑名单每行一个域名，也接受粘贴完整 HTTP/HTTPS 网址。网址会转换为域名，路径与查询不是单独的排除范围。例如 `https://example.com:8443/account` 保存为 `example.com`，排除该域名及其子域名、HTTP/HTTPS 和所有端口；`evil-example.com` 不受该项影响。IP 地址只匹配该 IP。大小写、国际化域名与域名末尾的点会规范化。不接受通配符、带用户名密码的网址、非 HTTP/HTTPS 地址；最多 200 项。

黑名单、模式和有效期在成功授权或应用后保存，供下次授权预填。每个授权使用自己的黑名单副本；修改一个标签页不会偷偷扩大其他标签页的范围，其他已授权标签页需分别应用修改。保存偏好不等于授权，扩展重载或后台重启后仍需用户重新点击授权。

当前网站在黑名单内时不能授权。主动导航到黑名单网站会在发出网页动作前拒绝；用户手动导航或网页重定向到黑名单网站则撤销控制。被排除的框架及其后代不提供 DOM 或操作引用。修改设置使旧任务租约和快照失效，任务须重新取得控制权与快照。如果应用的黑名单包含当前网站，立即停止此标签页控制并记住黑名单。

其他标签页仍需用户选择并授权。所有档位使用固定到期时间，默认 30 分钟，可选 15/30/60/120 分钟。停止按钮、Chrome 停止调试、后台重启都不会被自动重连撤销。没有新增 Chrome 安装权限：仍为 activeTab、debugger、nativeMessaging、storage、alarms，最低 Chrome 125。

富文本、菜单角色、开放 Shadow DOM 和 iframe 功能沿用 0.2.0 的实现。密码填写、文件上传、任意 JavaScript、Cookie/历史接口、浏览器内部页和扩展商店仍不支持；opaque/sandbox 特殊框架不能确认来源时跳过。截图包含可见页面像素，可能含黑名单框架画面；黑名单限制 DOM 和操作，不执行截图遮盖。准备草稿不等于授权发送消息、付款或签署协议。

本版扩展沿用 ID `afkdbekkfjphihnmmhhiahdncbkhogpd`。旧的扩展模式白名单选项不能用于新授权，避免老客户端默默产生全网站授权；已有授权也不会跨重载保存。
