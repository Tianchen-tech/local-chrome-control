# 0.2.0 开发版：控制模式与复杂页面

本版已实现功能，正式网站兼容性仍需分别验收。控制模式限制插件动作，Chrome 的 debugger 底层权限仍然存在。

## 使用方式

在目标页面点击“本地 Chrome 控制”。选择模式和有效期，点击“允许控制此标签页”。已有授权时，使用“应用设置并重新授权”；旧任务租约随即失效，必须重新取得租约及快照。

- 只读：读取、截图；点击、填写、文本插入、按键、滚动和导航都被控制器拒绝。
- 标准：当前网站可读写，支持普通输入、富文本、菜单角色、开放 Shadow DOM、同源 iframe。
- 扩展：添加本次任务的其他网站来源；列表内可在当前授权标签页连续导航。跨源内嵌网站使用另一个列表，不会因为允许顶层导航就自动获得内嵌内容权限。

输入完整 origin，例如 `https://mail.google.com`。路径、查询、通配符、用户名密码都不接受；子域名和端口不会自动继承授权。所有档位使用固定到期时间，默认 30 分钟，可选择 15/30/60/120 分钟。普通操作不会延长授权，到期由控制校验及清理闹钟撤销连接；用户可以主动续期。

控制范围仅限用户选择的标签页，不自动控制其他已打开标签或新弹出标签。网页或 MCP 请求没有修改模式、添加网站的接口。“全部停止”可在不连接本机程序时使用；后台重启不恢复授权。

## 新输入能力

`page_fill` 对普通 INPUT/TEXTAREA 保留原来的填写行为，对富文本编辑宿主选择其内容并通过 Chrome 输入纯文本，支持中文、多行和清空。它不会保留原有富文本格式，也不通过设置 innerHTML 代替浏览器输入。

新增 `page_type_text`：在明确目标的光标处插入纯文本。`mode=insert` 一次插入，`mode=characters` 逐 Unicode 字符发送，最多 500 字符。长文字建议一次插入；逐字发送可能因时限停止，结果不明时不得重放。空字符串插入不执行删除。

富文本、框架键盘输入需要最新快照中的 ref。每个字符及输入前后复核焦点与授权。封闭 Shadow DOM 可能隐藏实际密码目标，因此编辑宿主需要 DOM 结构验证；不能确认时拒绝输入。

Gmail、Notion、Slack 的复杂编辑器可能另有输入拦截和文档模型。本轮合成验收不等于这些正式服务已全部兼容，使用前要检查网页实际草稿。准备草稿不等于授权发送消息。

## 页面结构

快照显式收录菜单项、标签、选项、链接、文本框、开关及树项等 role-only 元素；遍历开放 Shadow DOM 并保留真实控件引用、祖先隐藏检查和遮挡检测。

iframe 使用独立隔离上下文；跨进程框架通过 Chrome flat sessions 处理，因此最低 Chrome 版本为 125。元素引用绑定快照及框架，刷新/重载/范围改变后失效。框架点击验证外层几何、缩放和实际命中目标；旋转或无法确认位置的框架拒绝输入。

限制：封闭 Shadow DOM 不提供自动输入；opaque/sandbox/about: 特殊框架不能确认来源时跳过。密码、文件上传、任意 JavaScript、Cookie/浏览历史接口和浏览器内部页仍不支持。截图包含整个可见页面，可能包含未提供 DOM 的内嵌内容；只在用户任务范围内截图。

## 合成验收

运行 `node scripts/fixture-modes.mjs`，然后打开：

- http://127.0.0.1:19320/?mode=readonly
- http://127.0.0.1:19320/?mode=standard
- http://127.0.0.1:19320/?mode=extended

在对应弹窗逐页授权。扩展页的“其他网站”与“内嵌网站”都加入 `http://localhost:19321`。授权后关闭弹窗。

验收脚本 `scripts/live-modes.mjs SESSION_ID MODE OUTPUT_DIRECTORY` 通过正常本机协议、租约及授权校验进行测试；它没有授权或升档接口。运行文字输入和框架测试时选中相应合成标签页，避免人为焦点改变。失败或不确定写入会停止验收，不自动重试。

本机已安装目录与 0.2.0 源码副本保留相同扩展 ID 和同一组五项 Chrome 权限。更新前备份位于工作区 `validation-0.2.0/before-update-0.1.1.zip`。商店 0.1.1 上传包和公开仓库尚未随本次开发更新。
