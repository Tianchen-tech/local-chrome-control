Privacy policy / 隐私政策

Effective: October 6, 2026 · Version 0.1.1

Publisher: Tianchen Shen. Contact: world8866171@gmail.com.

Scope and purpose / 处理目的

Local Chrome Control provides browser tools to a local MCP client for tabs you explicitly authorize. The first release supports macOS and requires a separate native companion. It is independent of Google and OpenAI.

Data processed / 处理的数据

When requested by your MCP client, the extension processes authorized-page titles, origins/URLs, visible text, DOM structure, ordinary form values, user-supplied action inputs and screenshots. URL query strings are omitted from exposed page metadata; page text or screenshots can nevertheless reveal sensitive information. The extension does not provide browser-history export, cookies export or password entry. It cannot guarantee that an authorized page contains no personal or sensitive information.

Where data goes / 数据流向

Browser results travel through Chrome Native Messaging and a local socket to your selected MCP client. The publisher does not operate a server collecting these results and the extension has no analytics, advertising or remote script loading. Your client, including Codex, may send tool results to its own model/service provider under that provider's policies and your settings. Therefore the overall workflow is not guaranteed to keep all data on your device.

Storage and retention / 保存与保留

Chrome local storage holds authorization state, request identifiers, parameter fingerprints, action status, timestamps and bounded result summaries for recovery and duplicate prevention. Expired action records are cleaned using a 24-hour retention cutoff, with records associated with live authorization retained until that authorization ends and cleanup runs. Runtime descriptors and sockets are local, owner-restricted files. Diagnostic output is designed to contain operation metadata rather than webpage bodies, screenshots, input values or authentication tokens. The MCP client may retain tool outputs and diagnostics separately; its retention is outside the extension's control.

Control and deletion / 控制与删除

You can stop a tab or all tabs in the popup. Cross-origin navigation and tab closure revoke control. Stopping does not erase already returned data or the duplicate-prevention ledger. Removing the extension removes its Chrome extension storage. Uninstall the native companion using its uninstall command; for full local cleanup remove its LocalChromeControl application-support directory only after all its sessions are stopped. Client-side conversation/tool-output retention must be managed in that client.

Sharing / 对外使用

The publisher does not sell processed data, use it for advertising, or use it for credit/lending decisions. If you email support or open a GitHub issue, that service and the publisher receive what you voluntarily provide. Do not post private page contents or credentials in public issues. GitHub hosts this documentation under its own privacy practices.

Changes / 更新

Changes to this policy will be published here with an updated effective date. Contact the public support address with questions.
