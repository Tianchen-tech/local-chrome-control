Installation / 安装指南

Publication is being prepared. There is no Chrome Web Store listing or install-ready companion release yet.

第一版仅支持 macOS，需 Node.js ≥22.22.2、Google Chrome 和 Codex 等兼容 MCP 客户端。只装浏览器扩展不够。

  1. Wait for the publisher to upload a store draft, bind its actual public key/item ID and publish a tagged companion download. Do not install the initial unbound checkout.
  2. Download the bound companion release and extract it to a stable directory.
  3. In that directory, preview with node scripts/install.mjs. Install with node scripts/install.mjs --install. It installs the native host for the current macOS user's Google Chrome.
  4. Configure an MCP stdio server using the absolute Node executable and server/mcp.mjs paths shown by the preview. Read the included control-local-chrome skill for consent, leases and write recovery.
  5. Install the published Chrome extension. Open a harmless test page and choose 允许控制此标签页 in its popup. Verify a snapshot, harmless form action and screenshot before using it on real tasks.

Troubleshooting

Run node scripts/doctor.mjs. Check the Native Messaging host, the actual store ID, Node executable and selected Chrome profile. A connection alone does not prove a page is controllable. Reauthorize only when you wish to continue; do not automatically replay an action after a timeout.

The initial unbound checkout fails with STORE_KEY_NOT_BOUND by design. A previous development installation may conflict with the same native-host name. Its installer will refuse to overwrite an unrelated origin; identify and uninstall the old installation through its own documented command first.

Uninstall

Run node scripts/install.mjs --uninstall from the same companion directory, then remove the extension and MCP server in their settings. Stop all sessions before manually clearing remaining local runtime files.
