安装流程

  1. 下载以上商店配套 ZIP，解压到稳定的本地目录，打开终端并切换到包含 package.json 的解压目录。运行程序仅使用 Node 内置模块，无需 npm install。
  2. Windows：node scripts/windows-setup.mjs 预览，再运行 node scripts/windows-setup.mjs --install 安装。macOS：node scripts/prepare.mjs，node scripts/install.mjs 预览，再运行 node scripts/install.mjs --install。
  3. 安装预览必须显示 chrome-extension://mppejcndepnklbbjjjdgbobmjfhhddfe/。将输出的 Node 和 server/mcp.mjs 绝对路径配置为本机 MCP STDIO server；生成的 .mcp.json 同样包含这些本机路径。
  4. 商店上架后从商店安装此扩展。审核前仅供测试者在 chrome://extensions 开启开发者模式并加载本包的 extension 文件夹；其 ID 必须为 mppejcndepnklbbjjjdgbobmjfhhddfe。打开本机合成验收页，在弹窗选择模式、时长并点击“允许控制此标签页”。按验收说明读取快照、执行无害输入/点击、查看截图和停止控制。

商店扩展与开发预览有各自的身份。本机主机允许的 extension origin 必须与实际扩展 ID 匹配；身份不一致时连接被拒绝。候选包在公钥未绑定时会拒绝安装，不会生成一个随机开发身份。

开发版 afkdbekkfjphihnmmhhiahdncbkhogpd 和商店版使用不同身份、相同本机主机名称，不能同时登记。安装器会拒绝覆盖其他身份。若决定迁移，请先停止开发版的全部控制，在原开发安装目录运行对应卸载命令撤销登记，再安装本包并更新客户端 MCP 路径。保留原目录，可按其指南重新安装恢复开发版。不要手动改 allowed_origins 或关闭来源检查。

诊断

node scripts/doctor.mjs 检查登记、权限和版本；以实际连接、页面读取与无害操作确认效果。依赖 Windows 系统 .NET / Windows PowerShell 的本机启动器编译；组织策略限制时通过正常管理员流程处理。不能关闭安全策略来强行安装。遇到结果不明的写操作，先 request_status 和新快照，不能自动重复点击。

撤销

先在扩展中停止连接。Windows：node scripts/windows-setup.mjs --uninstall；macOS：node scripts/install.mjs --uninstall。再移除扩展与 MCP 配置，并在所有会话结束后清理运行目录。
