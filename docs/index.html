本地 Chrome 控制

Tianchen Shen · Local Chrome Control 0.3.1

让兼容 MCP 客户端读取和操作你在弹窗手动授权的 Chrome 标签页。

提供只读、标准与扩展模式；支持普通和富文本输入、开放 Shadow DOM、授权范围内的 iframe，以及跨站连续操作与域名黑名单。

支持 macOS 和 Windows，需要 Node.js 22.22.2+、本机连接程序与兼容 MCP 客户端。页面与截图会返回客户端，客户端可能将其发送至模型服务。
