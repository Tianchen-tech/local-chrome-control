## 详细描述

面向使用 Codex 等兼容 MCP 客户端的用户，本地 Chrome 控制提供 OpenAI 官方 Chrome 控制方案之外的独立选择。它以减少浏览器自动化中的等待与重复操作为优化目标，围绕本机连接、授权设置和任务状态重新设计体验，让页面信息整理、草稿填写和重复网页操作更顺手。

【为什么尝试本插件】
• 更少重复授权：扩展模式下，同一授权标签页可跨网站连续操作，并用域名黑名单排除网站。
• 更清晰的操作状态：直接查看连接状态、授权剩余时间、正在控制的任务与最近操作。
• 改进 Windows 使用体验：0.3.1 修复 Windows 本机连接问题，并更新弹窗、图标与深色模式。
• 保留用户控制：三档范围、固定有效期，以及随时停止一个或全部标签页。

【安装要求】
支持 macOS 与 Windows，需要 Chrome 125 或更新版本、Node.js 22.22.2 或更新版本、单独安装的本机连接程序，以及兼容 MCP 客户端。只安装浏览器扩展不能开始控制，请先阅读安装指南。

【你可以做什么】
读取页面文字与控件、点击按钮和菜单、填写普通表单与富文本、选择下拉选项、滚动页面和截图。支持开放 Shadow DOM，以及授权范围内的同源和跨源 iframe。

【由你选择控制范围】
• 只读：读取页面与截图，不执行点击或输入。
• 标准：在当前网站内点击、输入和滚动。
• 扩展：在这个授权标签页内跨网站连续操作，并可用域名黑名单排除网站。

你可以选择授权有效期，随时停止一个或全部标签页。授权一个标签页不会自动授权其他标签页。任务独占与操作请求编号用于减少并发冲突和重复执行；结果不明时先检查页面，不自动重复点击。

【使用限制】
不支持密码填写、文件上传、封闭 Shadow DOM 和浏览器特殊页面，不绕过验证码或登录限制。黑名单限制来源的 DOM 读取与操作；主页面截图仍可能包含被排除内嵌框架的可见像素。不同网站和电脑环境的兼容性需分别验证。

【数据处理】
页面文字、普通表单内容、用户提供的输入和截图会通过本机连接返回所选 MCP 客户端。客户端可能将这些内容发送至模型服务并保存对话，本机连接不代表整个工作流都在本机运行。发布者不运营网页数据收集服务器，不投放广告或出售页面数据。请阅读隐私政策。

这是独立项目，与 Google 或 OpenAI 无隶属关系。

## 单一用途与权限说明

单一用途：让用户选择的本机 MCP 客户端读取和操作用户明确授权的 Chrome 标签页。

- activeTab：用户打开扩展时读取当前标签页标题与来源，明确授权目标。
- debugger：读取授权页面和框架的 DOM、发送可信输入/鼠标/滚轮、截图。权限较强；控制器额外限制到用户授权的标签页、网站范围、工具白名单与任务租约，不开放任意 CDP 或 JavaScript 接口。
- nativeMessaging：连接用户安装的本机主机，将工具请求和结果传给本机 MCP 客户端。
- storage：保存模式/有效期/黑名单偏好及有限去重账本，不保存可恢复的授权。后台重启仍要求重新授权。
- alarms：本机通信意外断线后的延迟重连；重连不新建授权或覆盖用户停止决定。

远程代码：扩展执行代码均随包提供。内部注入的是随包提供的页面函数；用户输入仅作为函数数据参数。没有下载或执行远程脚本，也没有任意 JavaScript/任意 CDP 的 MCP 工具。

## 数据分类建议与开发者认证

必核对 Website content（可见文字、DOM、表单、截图）与 Web/Browsing history（授权页 URL/标题，未请求 history API）。本机操作时间线含操作类型、时间和耗时，应按后台 User activity 定义核对。用于邮件或消息页时也会处理用户选定的个人通信；页面/截图可能含个人信息。请按实际用途和后台定义核对相应类别，不填写“完全不处理数据”。

页面数据只用于所述功能并交给用户指定的客户端；无广告、销售或信用评估用途。Limited Use、政策与开发者声明须由发布者依据实际后台文本亲自确认；本稿不能替其完成法律认证。
